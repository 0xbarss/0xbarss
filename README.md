### What I work on

**Embedded + Backend**
- [`edge-post`](https://github.com/0xbarss/edge-post) - STM32 nodes send binary sensor frames over TCP to a backend that writes them to PostgreSQL and pushes live readings to a dashboard over WebSocket. The backend can also send commands back down to the device.

**Backend**
- [`api-trace`](https://github.com/0xbarss/api-trace) - Give it an OpenAPI spec and it figures out what could break: auth issues, contract drift, latency regressions. Jobs go through a Redis queue and results stream to the browser over WebSocket.
- [`aero-deploy`](https://github.com/0xbarss/aero-deploy) - Self-hosted APK distribution. Uploads stream straight to disk, the binary manifest gets parsed for version info, and testers get a QR code to install directly. Built on Fastify and PostgreSQL.

**Systems**
- [`memory-allocator`](https://github.com/0xbarss/memory-allocator) - A heap allocator in C with First-Fit, Best-Fit, and Segregated Free Lists. Boundary tags, coalescing, and benchmarks against glibc to see where each strategy actually wins.
